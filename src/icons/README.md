# Feather icon subset

Source: https://github.com/feathericons/feather/tree/v4.29.2/icons
Version: v4.29.2 (pinned; no network access during builds).
License: upstream MIT, reproduced in LICENSE and dist/icons-LICENSE.txt.

The upstream SVG files are kept intact. The build extracts their geometry into
local SVG symbols, styled by .tg-icon: 24×24 viewBox, stroke 2, round caps/joins.
Only 17 glyphs used or demonstrated by the catalog are bundled.
This is Feather, not SF Symbols or an Apple-supplied asset set.
