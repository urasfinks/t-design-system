# Подвалы — спецификации компонентов

## Назначение категории

Папка `footers` содержит 1 превью — «Invoice Table», то есть таблицу счетов с
итоговой строкой и подписью **под** таблицей. Исходная категория отражает «подвал
таблицы», а не подвал сайта. По правилам группировки референс описан по фактической
семантике: это `tfoot` и `caption` у `.tg-table`. Рекомендации по подвалу сайта даны в
«Общих решениях» как правила композиции, без отдельной спецификации, потому что в
архиве нет соответствующих референсов.

## Общие решения категории

- **Подвал таблицы.** Итоги — `tfoot` с `th scope="row"` и `.tg-table__num`; подпись —
  `caption` (может располагаться визуально снизу через `caption-side: bottom`, оставаясь
  первым дочерним элементом таблицы).
- **Подвал сайта (правила композиции без референсов).** `footer` с `nav aria-label`
  для групп ссылок (`h2`-заголовки групп, `ul` ссылок), строкой копирайта и соцсетей
  (иконкокнопки с `aria-label`); фон `--background-panel`, разделитель
  `--border-subtle-color`; колонки `.tg-grid` → один столбец на мобильном (группы как
  `details.tg-disclosure`). Подпись к рассылке — forms F27.
- **Ответственность приложения** — данные и расчёт итогов.

## Спецификации компонентов

### FT1. Итоговая строка и подпись таблицы

Статус: `existing` · Приоритет: `P0` · Классы: `.tg-table-wrap`, `.tg-table`, `.tg-table__num`; предлагаемый `.tg-table--caption-bottom`

**Назначение**: показать итог по столбцу и пояснение к таблице.

**Состав**: таблица; строка итога в `tfoot`; подпись.

```html
<div class="tg-table-wrap" role="region" aria-labelledby="inv-caption" tabindex="0">
  <table class="tg-table tg-table--caption-bottom">
    <caption id="inv-caption">Последние счета</caption>
    <thead><tr><th scope="col">Счёт</th><th scope="col">Способ</th><th scope="col">Статус</th><th scope="col" class="tg-table__num">Сумма</th></tr></thead>
    <tbody><tr><th scope="row">INV-001</th><td>Карта</td><td><span class="tg-badge tg-badge--secondary">Оплачен</span></td><td class="tg-table__num">1 200,00 $</td></tr></tbody>
    <tfoot><tr><th scope="row" colspan="3">Итого</th><td class="tg-table__num">3 140,00 $</td></tr></tfoot>
  </table>
</div>
```

**API** (предлагаемое): `--caption-bottom` — `caption-side: bottom`, `--text-secondary`,
`--fs-sm`; `tfoot` — `--fw-semibold` и верхний разделитель `--border-color`.

**Варианты из референсов**: таблица счетов с итогом и подписью (1).

**Состояния**: default, empty (итог не показывается), loading (dashboards D5).

**Поведение и ответственность приложения**: расчёт итога, форматирование валюты.

**Адаптивность**: как dashboards D1; в `--stack` итог — отдельная строка-карточка.

**Доступность**: `caption` остаётся первым дочерним элементом; итог — `th scope="row"`.

**Токены и связь с TDS**: `--border-color`, `--text-secondary`, `--fw-semibold`.

**Критерии готовности**: итог выровнен по разрядам со столбцом сумм.

**Референсы** (1):

- `felipemenezes098--table-01--aad5f8cc.webp` — Invoice Table
