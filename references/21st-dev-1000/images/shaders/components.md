# Шейдеры и визуальные эффекты — спецификации компонентов

## Назначение категории

Папка `shaders` (9 превью): WebGL/Canvas-эффекты — фоновые поля и волны,
«металлические» и «жидкие» кнопки, шейдерный аватар, переход слайдов с рябью. Для TDS
это **только декоративный опциональный слой**. Базовый интерфейс никогда не требует
WebGL; эффект не меняет палитру, не несёт смысла и не влияет на семантику, фокус и
раскладку. Демо-код с собственными шейдерами в систему не переносится — переносится
контракт слоя: где он лежит, как получает цвета, как ставится на паузу и что
показывается без него.

## Общие решения категории

- **Декоративность.** Элемент эффекта — `canvas` или `div` с `aria-hidden="true"`,
  `pointer-events: none`, без фокуса; весь текст и все действия — в обычном DOM над ним.
- **Палитра.** Шейдер получает цвета из вычисленных CSS-свойств
  (`getComputedStyle(root).getPropertyValue('--accent-main')` и т. п.) и
  перечитывает их при смене темы (MutationObserver на атрибуте темы,
  `prefers-color-scheme`). Собственные цвета (неон, хром, золото) запрещены; «металл» —
  это градиент яркости одного цвета роли.
- **Фолбэк.** Без WebGL (нет контекста, ошибка компиляции, `prefers-reduced-motion`,
  `prefers-reduced-data`, экономия батареи) показывается статичная CSS-версия: сплошной
  фон или один неподвижный кадр. Компонент под эффектом выглядит законченным сам по себе.
- **Reduced motion.** Анимация останавливается полностью; допустим один статичный кадр.
- **Производительность.** Один общий WebGL-контекст на страницу для нескольких
  элементов (как в референсе 4); `requestAnimationFrame` только когда элемент в
  viewport (IntersectionObserver) и вкладка видима (`visibilitychange`); ограничение
  DPR до 2; пауза при `pointer: coarse` по умолчанию; бюджет — без заметной просадки
  кадров при прокрутке.
- **Слои.** Эффект — в изолированном контексте наложения (`isolation: isolate` у
  родителя), `z-index` ниже содержимого; не использует `--z-overlay`/`--z-toast`.
- **Подключение.** Только через модуль эффектов (`effects.mjs`) по явному атрибуту
  (`data-tg-effect="..."`); основной CSS и `ui.mjs` не меняются.
- **Ответственность приложения** — решение подключать эффект, загрузка модуля,
  контроль производительности на целевых устройствах.

## Спецификации компонентов

### SH1. Декоративный слой фона

Статус: `new` · Приоритет: `P2` · Предлагаемые классы/атрибуты: `.tg-effect-layer`, `data-tg-effect="field|waveform"`

**Назначение**: анимированный абстрактный фон секции или hero (поле частиц, волна,
кольцо света).

**Состав**: родитель с содержимым; слой эффекта за содержимым; статичный фолбэк.

```html
<section class="tg-container tg-col tg-gap-4" style="isolation: isolate" aria-labelledby="sh1-title">
  <canvas class="tg-effect-layer" data-tg-effect="field" aria-hidden="true"></canvas>
  <h1 id="sh1-title">Свет в каждой детали</h1>
  <a class="tg-btn tg-btn--primary" href="/start">Начать</a>
</section>
```

**API** (предлагаемое): `.tg-effect-layer` — `position: absolute; inset: 0; z-index: -1;
pointer-events: none`; фон-фолбэк `--background-main` (или `--accent-soft` для
акцентной секции); `data-tg-effect` выбирает программу; интенсивность —
документированное `--effect-intensity` (0…1).

**Варианты из референсов**: динамическая волна (1), поле-портал (6).

**Состояния**: running, paused (вне viewport/вкладка скрыта), static (reduced motion,
нет WebGL), failed (тихий переход в static).

**Поведение и ответственность приложения**: подключение модуля; модуль сам ставит паузу
и восстанавливает контекст после `webglcontextlost`.

**Адаптивность**: на мобильном — static по умолчанию; разрешение canvas по размеру
секции с ограничением DPR.

**Доступность**: `aria-hidden`; контраст текста проверяется на самом светлом кадре;
нет мигания чаще 3 раз в секунду (WCAG 2.3.1).

**Токены и связь с TDS**: `--accent-main`, `--background-main`, `--accent-soft`.

**Критерии готовности**: страница без модуля и без WebGL полностью функциональна;
нет новых цветов; reduced motion останавливает анимацию.

**Референсы** (2):

- `dhileepkumargm--dynamic-waveform--b7fb2d03.webp` — Dynamic Waveform
- `mengto--portal-field--c0c4f342.webp` — Portal Field

### SH2. Эффект поверх кнопки

Статус: `extend` · Приоритет: `P2` · Расширение buttons B19: `data-tg-effect="metal|glass|liquid|glow"` на `.tg-btn`

**Назначение**: выразительная граница или материал одной ключевой кнопки на
маркетинговой странице.

**Состав**: обычная `.tg-btn`; декоративный слой-рамка или подложка внутри кнопки
(`span` с `aria-hidden`), рисуемый общим контекстом.

```html
<a class="tg-btn tg-btn--primary" href="/pro" data-tg-effect="metal">
  <span class="tg-effect-layer" aria-hidden="true"></span>
  Перейти на Pro
</a>
```

**API** (предлагаемое): слой повторяет `border-radius` кнопки, рисует только рамку
или блик; заливка, цвет текста, высота, фокус-кольцо, `disabled`, `aria-busy` — от
`.tg-btn` без изменений; эффект выключается в disabled и loading.

**Варианты из референсов**: «индукционная» рамка (2), Lumen — обсидиановое стекло (3),
металлические кольца с общим контекстом (4, 5), тактильная «жидкая» кнопка (8).

**Состояния**: idle (статичная рамка), hover/focus (эффект активен), pressed (эффект
не мешает волне нажатия), disabled/loading (без эффекта).

**Поведение и ответственность приложения**: подключение; не более одной-двух таких кнопок на экран.

**Адаптивность**: на сенсорных — статичная рамка.

**Доступность**: контраст текста ≥ 4.5:1 на любом кадре; фокус-кольцо не перекрывается
эффектом; reduced motion — статично.

**Токены и связь с TDS**: `--accent-main`, `--accent-strong`, `--radius-control`.

**Критерии готовности**: при отключённом модуле — обычная `.tg-btn` без визуальной
разницы в размерах.

**Референсы** (5):

- `mengto--induction-button--4d0328ca.webp` — Induction Button
- `anark17r--lumen-button--a350b6e5.webp` — LumenButton
- `arihantcodes-1f7b8c4d--metal-button--be7ff94b.webp` — Metal Button
- `hyperiux--metallic-button--413d3b93.webp` — Metallic Button
- `mengto--tactile-button--198f25fb.webp` — Tactile Button

### SH3. Эффект аватара

Статус: `extend` · Приоритет: `P2` · Расширение `.tg-avatar`: `data-tg-effect="orb"`

**Назначение**: «живой» аватар ассистента или пользователя без фото (инициалы на
переливающемся фоне).

**Состав**: `.tg-avatar` с инициалами; слой эффекта внутри круга.

```html
<span class="tg-avatar" data-tg-effect="orb">
  <span class="tg-effect-layer" aria-hidden="true"></span>
  <span class="tg-avatar__initials">АБ</span>
</span>
```

**API** (предлагаемое): слой обрезается `.tg-avatar__clip`-геометрией; цвет — оттенки
`--accent-main`; инициалы остаются читаемыми (`--avatar-initials-color` поверх
затемнения при необходимости).

**Варианты из референсов**: шейдерные аватары с инициалами (7).

**Состояния**: static, animated (только для ассистента в состоянии «думает» — см.
ai-chats A10), selected (существующее кольцо).

**Поведение и ответственность приложения**: когда анимировать.

**Адаптивность**: на маленьких размерах (≤ 32 px) — static.

**Доступность**: имя аватара не меняется; анимация — дополнение к текстовому статусу.

**Токены и связь с TDS**: `--accent-main`, `--avatar-initials-color`.

**Критерии готовности**: контраст инициалов ≥ 4.5:1 на любом кадре.

**Референсы** (1):

- `isaiahbjork--primitive-avatar--83d12cee.webp` — Shader Avatar

### SH4. Переход слайдов с эффектом

Статус: `extend` · Приоритет: `P2` · Расширение `.tg-carousel` (navigation N16, galleries G1): `data-tg-effect="ripple"`

**Назначение**: переход между изображениями карусели с рябью/искажением.

**Состав**: обычная карусель; canvas-слой, отрисовывающий переход между текущим и
следующим изображением.

```html
<section class="tg-carousel" data-tg-effect="ripple" aria-roledescription="карусель" aria-label="Озёра">
  <canvas class="tg-effect-layer" aria-hidden="true"></canvas>
  <div class="tg-carousel__viewport" tabindex="0">…слайды G1…</div>
</section>
```

**API** (предлагаемое): эффект проигрывается поверх смены слайда длительностью
≤ `--duration`×3; слайды и подписи — в DOM как обычно; без эффекта — fade/snap G1.

**Варианты из референсов**: водная рябь в карусели (9).

**Состояния**: idle, transitioning, static.

**Поведение и ответственность приложения**: загрузка изображений как текстур (CORS),
отмена перехода при быстром переключении.

**Адаптивность**: на мобильном — обычный snap.

**Доступность**: переход не задерживает смену доступного содержимого; reduced motion —
без эффекта.

**Токены и связь с TDS**: не вводит цветов.

**Критерии готовности**: карусель полностью работает при отключённом эффекте.

**Референсы** (1):

- `kedhareswer--water-ripple-carousel--d175fa94.webp` — Water Ripple Image Carousel

## Порядок реализации

1. **P2:** общий загрузчик эффектов в `effects.mjs` (один контекст, пауза, фолбэк, чтение
   токенов) → SH1 → SH2 (совместно с buttons B19) → SH3 → SH4.
2. Каждый эффект документируется в каталоге эффектов со статичным фолбэком рядом.
