# Текст и редактор — спецификации компонентов

## Назначение категории

Папка `text` (4 превью): редактор форматированного текста, выделение блоков,
плавающая панель у выделения и анимированный заголовок. Редактор — сложный виджет:
TDS оформляет оболочку, панель инструментов, состояния блоков и всплывающие слои,
а модель документа, команды форматирования и сохранение — ответственность приложения
и выбранного движка (ProseMirror, Lexical, TipTap и т. п.).

## Общие решения категории

- **Типографика содержимого** — системный шрифт, 16 px, высота строки 1.5; заголовки
  с умеренным весом и трекингом не плотнее −0.03 em; ширина текста до
  `--layout-reading-width` (48rem).
- **Панели инструментов** — `.tg-toolbar--compact` с `role="toolbar"` и роумингом
  фокуса (buttons B13); кнопки форматирования — `aria-pressed` (B7).
- **Выделение** — фон `--accent-soft`, рамка выбранного блока 2 px `--accent-main`;
  не меняет текст и раскладку.
- **Ответственность приложения** — модель документа, команды, история, вставка,
  совместное редактирование, автосохранение.

## Спецификации компонентов

### T1. Оболочка редактора и выделение блоков

Статус: `new` · Приоритет: `P2` · Предлагаемые классы: `.tg-editor`, `__toolbar`, `__content`, `__status`, `.tg-editor__block[aria-selected]`

**Назначение**: редактирование документа с форматированием (заголовки, списки, код,
ссылки) и выбор блоков целиком.

**Состав**: верхняя строка (путь документа, статус сохранения, «Поделиться»); панель
форматирования; область `contenteditable`; блоки с состоянием выбора; строка «Изменено …».

```html
<section class="tg-card tg-editor" aria-labelledby="doc-title">
  <header class="tg-row tg-justify-between">
    <nav class="tg-breadcrumbs" aria-label="Путь"><ol><li><a href="/docs">Предложения</a></li><li aria-current="page" id="doc-title">Редизайн портала</li></ol></nav>
    <span class="tg-editor__status tg-text-sm tg-text-muted" role="status">Сохранено</span>
  </header>
  <div class="tg-toolbar tg-toolbar--compact tg-editor__toolbar" role="toolbar" aria-label="Форматирование" aria-controls="doc-body">
    <button class="tg-icon-btn tg-icon-btn--ghost tg-toggle" type="button" aria-pressed="false" aria-label="Жирный">B</button>
  </div>
  <div class="tg-editor__content" id="doc-body" contenteditable="true" role="textbox"
       aria-multiline="true" aria-labelledby="doc-title">
    <h2>Объём работ</h2><p>…</p>
  </div>
</section>
```

**API** (предлагаемое): `__content` — типографика содержимого (вложенные `h2–h4`, `ul`,
`ol`, `code`, `blockquote` получают стили TDS внутри редактора); фокус — кольцо на
`__content`; выбранный блок — `aria-selected="true"` или `data-selected` с рамкой
`--accent-main` и фоном `--accent-soft`.

**Варианты из референсов**: выделение блоков с синей подложкой и выбором протягиванием
(3), полный редактор с путём, статусом и панелью (4).

**Состояния**: idle, focused, saving, saved, error (сохранение не удалось — `.tg-notice`),
read-only (`contenteditable="false"`), block selected.

**Поведение и ответственность приложения**: команды (Cmd/Ctrl+B/I/U, K — ссылка),
синхронизация `aria-pressed` с текущим выделением, Escape в блоке → выбор блока,
стрелки ↑/↓ — соседний блок, Delete — удалить выбранные.

**Адаптивность**: панель прокручивается горизонтально или сворачивается в «Ещё»; на
мобильном панель прилипает над клавиатурой (`--tg-keyboard-inset`).

**Доступность**: `role="textbox"` + `aria-multiline` (если движок не даёт своей
семантики); объявление выбора блоков в status; сочетания клавиш документированы.

**Токены и связь с TDS**: `--layout-reading-width`, `--accent-soft`, `--accent-main`, `--font-family`.

**Критерии готовности**: работает с движком-примером; панель — полный контракт toolbar.

**Референсы** (2):

- `platejs--block-selection--3043c88e.webp` — Block Selection
- `uvain--rich-text-editor-toolbar--82433e25.webp` — Rich Text Editor

### T2. Панель у выделения

Статус: `new` · Приоритет: `P2` · Предлагаемый класс: `.tg-selection-toolbar` (поверхность плавающего слоя + `.tg-toolbar--compact`)

**Назначение**: действия над выделенным фрагментом — уточнить, прокомментировать,
применить предложение.

**Состав**: плавающая панель над/под выделением; 2–5 действий; необязательная
плашка результата («Применено»).

```html
<div class="tg-toolbar tg-toolbar--compact tg-toolbar--floating tg-selection-toolbar"
     role="toolbar" aria-label="Действия с выделенным">
  <button class="tg-btn tg-btn--primary tg-btn--sm" type="button">Уточнить</button>
  <button class="tg-btn tg-btn--ghost tg-btn--sm" type="button">Комментировать</button>
</div>
```

**API** (предлагаемое): позиционирование по `Range.getBoundingClientRect()` через
локальные свойства `--anchor-x`/`--anchor-y`; CSS Anchor Positioning как улучшение.

**Варианты из референсов**: «Refine / Comment» над выделенной строкой с отметкой
«Applied» (1).

**Состояния**: hidden, visible, action busy, applied.

**Поведение и ответственность приложения**: показ при непустом выделении, доступ с
клавиатуры (сочетание, например Alt+F10 — переход в панель), Escape — возврат к тексту.

**Адаптивность**: на мобильном — над системным меню выделения или в нижней панели.

**Доступность**: панель доступна без мыши; результат объявляется.

**Токены и связь с TDS**: `--background-raised`, `--shadow-overlay`, `--z-overlay`.

**Критерии готовности**: не перекрывает выделенный текст; клавиатурный вход документирован.

**Референсы** (1):

- `21st--lp-contextual-toolbar-anchor--115468a0.webp` — Selection-anchored tools

### T3. Анимированный заголовок

Статус: `composition` · Приоритет: `P2` · Состав: заголовок + `.tg-text-accent` для выделенного слова

**Назначение**: маркетинговый заголовок со сменяющимся или выделенным словом.

**Состав**: статичная часть; акцентная часть.

```html
<h1>Делайте сайты <span class="tg-text-accent">со скоростью света</span></h1>
```

**API**: новых классов нет. Смена слов по таймеру (2) — P2-эффект: все варианты
доступны в одной фразе для диктора (`aria-label` у заголовка или видимый статичный текст),
анимация — `opacity`/`transform`.

**Варианты из референсов**: заголовок с выделением «light speed» (2).

**Состояния**: статичный; анимируемый.

**Поведение и ответственность приложения**: таймер смены слов, пауза.

**Адаптивность**: перенос по словам; акцентная часть не разрывается.

**Доступность**: reduced motion — статичный текст; смена слов не объявляется в live region.

**Токены и связь с TDS**: `--accent-readable` (через `.tg-text-accent`).

**Критерии готовности**: без анимации смысл сохраняется.

**Референсы** (1):

- `nexus-ui--animated-select-headline--299ac32f.webp` — Animated Select Headline
