Один файл — и можно собирать

Подключите CSS. Добавьте разметку. Настройте под себя.

Обычный HTML
<link rel="stylesheet"
  href="t-design-system.min.css">

<button class="tg-btn tg-btn--primary">
  Начать
</button>
Ваши настройки
:root {
  --button-color: #18745b;
  --button-text-color: #fff;
  --radius: .75rem;
  --space-4: 1rem;
}
reset→tokens→themes→base→components→utilities→visibility
