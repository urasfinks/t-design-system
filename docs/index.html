Нижняя раскрывающаяся панель

Обычный tg-list с закреплением внизу: итог — первая строка списка, позиции раскрываются под ней. Внешняя оболочка отвечает только за расположение; оформление задают tg-list и tg-list-item.

Что входит в TDS

tg-page-shell · tg-page-header · tg-page-content
Шапка с safe area и область контента с резервом под composer. Узкая колонка: tg-container tg-container--reading.
tg-toolbar · tg-toolbar--responsive
Панель с действиями по краям. На мобильном элементы растягиваются; tg-tabs--responsive занимает всю ширину.
tg-comment · tg-thread
Аватар, метаданные, текст и действия. На телефоне текст на всю ширину, вложенные ответы с компактным отступом.
tg-composer · tg-reply-preview
Закреплённая панель, растущее поле, кнопка отправки, подпись и обрезаемая цитата ответа.
tg-media · tg-source-link
Изображение без обрезки в пределах окна и строка ссылки на источник. Используют существующий tg-modal.

Граница CSS и поведения

TDS определяет размеры, цвета, отступы и адаптивность. Приложение хранит данные, отправляет сообщения и управляет фокусом. JavaScript измеряет высоту composer и клавиатуры через --tg-composer-height и --tg-keyboard-inset, а также подстраивает высоту textarea.

Токены: --layout-reading-width (48rem), --composer-reserved-size (10rem), --composer-input-max-size (2 × space-16), --media-max-size (55dvh). Типографика и существующие контролы не переопределяются.

JavaScript примера · Слоты и ограничения интеграции описаны в README → Screen compositions.
