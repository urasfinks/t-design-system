# Рефактор каскада исходного TDS · 26.10.2026

Работа выполнена в t-design-system, без переноса дизайна или API из v2.
Правило побайтовой заморозки core отменено. Внешний вид текущего исходника
зафиксирован до изменения в tests/fixtures/cascade-baseline/.

## Устройство после изменения

- tokens: размеры, шрифт, motion и SVG-данные стрелок select;
- themes: палитра, выбор стрелок и коэффициент hover каждой темы;
- base: наследование типографики, focus/disabled/hidden и подключение control-states;
- control-states: один механизм перехода, hover и прозрачного press-отклика;
- buttons: общая геометрия и paint, варианты задают idle/hover/color параметры;
- forms: окончательная геометрия select и его стрелка;
- avatar: обычные/интерактивные бейджи и их семантические состояния;
- compositions: выравнивание composer рядом с его основными правилами;
- bottom-panel: общие параметры двух триггеров;
- utilities и visibility: прежний приоритет над компонентами.

Extensions больше не дописывает переопределения после ядра. Старые пути extensions
и control-hover работают как совместимые SCSS-входы. Независимый control-hover
сохраняет reset/base/focus/disabled/visibility. JavaScript, HTML и CSS каталога,
публичные tg-* классы, значения палитры, размеры и скругления не изменены.
