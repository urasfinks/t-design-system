# Визуальная совместимость при рефакторинге ядра

Правило заморозки исходников на 678b61e1 отменено по запросу пользователя.
Старый коммит остаётся частью истории, но не запрещает изменение core CSS.

## Текущий эталон

Перед рефакторингом 26.10.2026 сохранены CSS текущего исходного t-design-system
(cf53681) и CSS каталога в tests/fixtures/cascade-baseline/. manifest.json содержит
контрольные суммы эталона и исходной разметки каталога. Эталон не берётся из v2.

## Что проверяется

- Публичные tg-* классы и пути SCSS-импорта.
- Вычисленные свойства всех элементов каталога и их ::before/::after.
- Совпадение пикселей всего каталога: Light/Desktop Dark/iOS Dark,
  320/390/1440 px, исходный/зелёный/фиолетовый акцент.
- Hover, press, focus, disabled, native controls, иконки, effects и композиции
  проверяются существующими отдельными браузерными сценариями.
- Импорт control-hover отдельно сохраняет reset/base, focus, disabled и hidden.

В Chromium снимок сначала стабилизируется: два последовательных кадра должны
совпасть. Первый full-page screenshot может закончить переразметку balanced text;
промежуточный кадр не является эталоном визуала. Сравнение строгое во всей области
каталога. Единственный узкий допуск — не более восьми пикселей сглаживания внутри
неизменённых текстовых brand-mark: Chromium иногда растеризует точку логотипа
немного иначе после замены stylesheet. При этом HTML, все computed styles и
геометрия логотипа контролируются отдельно; область логотипа целиком не маскируется.

## Где живут правила

Tokens и themes содержат переменные и их значения. Base включает общий state engine.
Кнопки, select, badge и composer содержат свои финальные правила в модулях владельцев.
Extensions — совместимый вход, а не таблица поздних исправлений. Control-hover —
совместимый вход к base; реализация общих состояний находится в control-states.

HTML/CSS каталога не переработаны. Цвета, размеры, шрифты, рамки и радиусы сохраняются.
Для согласованного изменения дизайна эталон обновляют отдельно и явно; рефакторинг
не должен незаметно менять его для получения зелёного теста.

## Эталон хранит разметку 27.10.2026

С начала полной реализации компонентов эталон хранит и разметку каталога
(`tests/fixtures/cascade-baseline/index.html`). Браузерный тест рендерит эту сохранённую
разметку с CSS эталона и с текущим CSS; юнит-тест проверяет, что каждый раздел и каждое
правило примера сохранённой разметки остались в текущем каталоге. Поэтому новые примеры
больше не требуют обновлять эталон: проверяется только, что прежнее содержимое выглядит
и ведёт себя как раньше.

## Согласованное изменение 28.10.2026: вторичные кнопки без рамки

По решению владельца `.tg-btn--secondary` и `.tg-icon-btn` различаются только заливкой
(вариант B из сравнения: тональная кнопка, как gray-кнопка Apple и tonal-кнопка Material 3).
Рамка 24 % поверх серой заливки давала две границы сразу. Цвет рамки теперь — токен
`--button-border-color`: прозрачный по умолчанию, при `prefers-contrast: more` — как у
остальных действий. Прозрачная граница 1px сохраняет размеры. Соседние кнопки на одной
заливке в `--attached` и сплит-кнопке делит тонкая линия цвета текста. Фильтры, ссылки-бейджи
и аватар-кнопки сохраняют рамку. Эталонный CSS и правило примера B1 обновлены явно.

### Уточнение 28.10.2026: едва заметная рамка и ровные клавиши

Договорённость «всё кликабельное обведено» сохраняется: у вторичной и иконочной кнопок
рамка возвращена, но едва заметная — `--button-border-color` равен rgba(0, 0, 0, .04) в
светлой теме и rgba(255, 255, 255, .02) в тёмных. У клавиш `.tg-kbd` убрана утолщённая
нижняя граница (`border-block-end-width: 2px`), край теперь ровный. Эталонный CSS обновлён явно.
