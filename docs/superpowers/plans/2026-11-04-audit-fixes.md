# Исправления аудита TDS

**Цель:** устранить все замечания аудита от 4 ноября, сохранив компоненты,
примеры, якоря, палитры и текущий визуальный язык. Пользователь разрешил
весь проход сразу и запретил коммиты. Работа выполняется в текущей папке.

**Решения:** поиск ранжирует точные классы владельцев из подписей семейств;
HTML берётся из живой разметки каждого варианта, полный пример остаётся;
компактные действия подключают общий миксин невидимой цели `--control-h`.
Каталог использует публичные варианты и утилиты вместо оформления внутренностей.

копирование сообщает успех/ошибку и не парсит HTML; расширенные цели не перекрывают
соседние действия; полный пример и старые якоря доступны; каталог работает без JS.
