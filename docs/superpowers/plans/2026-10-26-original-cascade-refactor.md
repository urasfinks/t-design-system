# Рефактор каскада исходного TDS с сохранением внешнего вида

Пользователь отменил запрет изменения ядра и выбрал исходный t-design-system визуальным эталоном. t-design-system-2 не является источником дизайна или кода для этого изменения.

- [x] Зафиксировать текущие CSS и каталог до изменения как визуальный эталон. Заменить byte-equality исходников сравнением публичного API, computed styles и пикселей.
- [x] Перенести token/theme-исправления из extensions в tokens/themes; размеры SVG/select — в владельцев; размеры и stacked/ghost кнопок — в buttons; интерактивный badge — в avatar; composer — в compositions.
- [x] Подключить общий механизм состояний из base. Компоненты задают параметры idle/hover, а не копируют hover/transition. Удалить поздние переопределения и сохранить совместимые выборочные SCSS entry points.
- [x] Проверить три темы и три акцента, ширины 320/390/1440, idle/hover/pressed/focus/disabled, типографику, геометрию, пиксели каталога, отдельные SCSS imports и существующие сценарии.
- [x] Удалить правило заморозки из действующей документации; описать ownership токенов, общей базы, вариантов и utilities. Обновить сборку и отчёт фактических проверок.

Критерий результата: исходная разметка каталога и публичные классы сохранены; внешний вид совпадает с эталоном до рефактора. Никаких решений v2, новых цветов, шрифтов, размеров или скруглений.
