# Теги с подсказками

Согласовано в чате: отдельный блок рядом с существующими тегами. Подсказки работают как в «Командах»; для нового значения появляется строка «Добавить „…“», доступная мышью и Enter. Повторы не добавляются.

Подход: расширить существующий combobox параметром `data-allow-custom` для множественного выбора. Отдельный обработчик дублировал бы фильтрацию и клавиатурную навигацию. Используются существующие компоненты и оформление, обычные теги и команды сохраняются.

Свои значения обрезаются по краям; сравнение повторов без учёта регистра. При точном совпадении строка создания не показывается. Пустой ввод не создаёт тег. Выбранные значения передаются скрытыми полями `tags[]` нового примера. Escape закрывает список без добавления.
