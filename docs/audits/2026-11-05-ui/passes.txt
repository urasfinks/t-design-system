1. Impeccable. Статический detector: 18 предупреждений; rendered mobile: 110. F02 подтверждён. Остальные предупреждения классифицированы в triage-impeccable.json. Технический проход использовал последующие измерения для окончательной оценки 14/20; оценка не независима от общего набора доказательств.

2. UI/UX Audit audit.js. Выполнен оригинальный измерительный скрипт в 6 конфигурациях. Контрастные предупреждения отклонены после canvas/цветовой перепроверки. Все target warnings не приняты автоматически; подтверждён F03. Ограничение движка: первые 6000 DOM-узлов и около 1200 текстовых узлов, поэтому весь каталог им не покрыт. Полные наблюдения — 02-measurements.json.

3. EliaAlberti heuristic audit. Цель: новый разработчик ищет компонент и получает HTML. Снимки 03-start/search/buttons/html/mobile-forms; дополнительно contact sheet и подтверждённые дефекты F02/F03 из других проходов. Nielsen #3: Escape и возврат фокуса; #6/#10: поиск классов и локальная документация; Norman Discoverability: явное раскрытие HTML. Новых самостоятельных блокеров на этих снимках не найдено. По статическим снимкам не оценивались screen reader/keyboard/motion. annotations.html показывает наблюдения и позитивные находки без выдуманных дефектов.

4. Brumley pipeline. Native Playwright API + axe-core + Lighthouse вместо MCP wrappers. 9 исходных axe scans и 1 search-open scan. Подтверждены F01/F04/F05/F06; F07/F08 — предложения по Lighthouse. Отчётные категории не равны числу узлов. Lighthouse performance 73, остальные категории 100, но это не означает отсутствие дефектов динамических состояний.

5. Flagrare adapted walkthrough. 151 заголовок посещён, 1147 элементов инвентаризированы, основной сценарий desktop/mobile пройден. Проверены empty-search, Escape/focus return, HTML раскрытие/copy fallback. Дополнительные standalone demos: compositions/workspace/bottom-panel; icon-browser — fragment. Исчерпывающий обход каждого контрола оригинальной методики НЕ выполнен; перечень непроверенных контролов сохраняется в inventory, каждый элемент нельзя считать проверенным по одному его присутствию.
