# Исправления после просмотра каталога

Реализованы все семь замечаний из живого просмотра. Изменения остаются в рабочем
каталоге; сервер отдаёт новую сборку после перезагрузки вкладки.

1. **Сравнение изображений.** Нативная дорожка учитывает ширину thumb, поэтому
   её центр совпадает с `--compare`, границей наложения и круглой ручкой.
   На 0/100% половина ручки скрывается за краем. Прямоугольная обёртка
   `tg-compare__control` ограничивает расширенный input; общий media-mask
   остаётся единственным владельцем скруглённого края, без светлых артефактов.
2. **Навигационное меню.** Наведение открывает предпросмотр; первый клик
   подтверждает открытие, следующий закрывает. Таймер наведения не может
   заново открыть явно закрытую панель. Клавиатура, Escape и клик снаружи
   работают без блокировки событий на время перехода.
3. **Стопка уведомлений.** Переполнение ограничивается синхронным удалением
   самого старого элемента. Исправлен бесконечный цикл, который раньше
   возникал уже на шестом уведомлении из-за отложенного удаления в цикле while.
   Повторное закрытие идемпотентно, обычное исчезновение остаётся анимированным.
4. **Выбор цвета.** Образец открывает `tg-color-picker[popover]` с общими
   floating surface, скруглениями, отступами и позиционированием. Popup использует
   существующий HSV-движок; HEX, ползунки и готовые цвета синхронизированы.
   Готовый цвет можно восстановить после изменения HSV. Без JS остаётся
   нативный color input. При JS его значение формы сохраняется, а popup
   открывает семантическая кнопка с общей расширенной областью нажатия.
5. **Изображения карточек.** Удалены `tg-mt-0`/`tg-mb-0` из четырёх media-примеров
   каталога и workspace: они отменяли правильный отрицательный margin владельца.
   Изображения теперь начинаются у рамки, без пустой полосы.
6. **Подробнее.** Карточка больше не участвует в View Transition. Нативный диалог
   открывается отдельно; при закрытии фокус возвращается к исходной кнопке.
7. **HTML.** Публичный `tg-disclosure--compact`, одна открытая секция через native
   `details[name]`, два внутренних блока: `tg-code-block` и строка копирования.
   Вложенной карточки и двойной рамки нет; длинный код прокручивается внутри,
   не расширяя аккордеон. Статический пример композиций использует тот же renderer.
   Исходный HTML сохраняется до demo-enhancement, включая нативные fallback.

## Регрессионные сценарии

- `compare-alignment.browser.mjs`: 0/25/50/75/100%, три ширины, LTR/RTL,
  настоящее перетаскивание, Home/End, все темы.
- `nav-menu-pointer.browser.mjs`: наведение → клик, повторный клик, Escape,
  внешнее нажатие, отмена таймеров, клавиатура, мобильный viewport.
- `toast-burst.browser.mjs`: двадцать синхронных активаций, максимум пять узлов,
  дальнейшее закрытие и отзывчивость event loop.
- `card-media-edge.browser.mjs`: геометрия каталога и workspace в трёх темах.
- `color-field-popup.browser.mjs`: bounds, скругление/padding, точные preset HEX,
  HSV-синхронизация, восстановление preset, Escape/focus и неподвижная карточка.
- `code-viewer.browser.mjs`: одна открытая секция, цель не меньше 44 px,
  два блока без вложенной рамки, отсутствие расширения viewport, точное копирование.

Новые сценарии запускаются в обоих движках вместе с существующими media,
rounded-media, catalog-audit/search, disclosure, option, workspace и first-paint
проверками. Результаты и логи находятся в [followup-evidence](followup-evidence/).
Проверка реального физического touch и screen reader отдельно не выполнялась.
Исторические сбои полного набора из [предыдущей реализации](implementation.md)
не выдаются за исправленные этими изменениями.

## Уточнение HTML-аккордеона

После проверки пользовательского скриншота удалена вложенная card-поверхность.
`tg-disclosure--embedded` оставляет один верхний разделитель без боковых рамок
и скруглений; содержимое disclosure получает верхний отступ `space-3`.
Внешняя панель примера единолично обрезает углы, stage больше не скругляется
внутри неё. Проверка дополнена геометрией границ, углов и отступа над pre.
